Onde publicar o EcoVida Urbana

Um site que ensina sustentabilidade também precisa de uma hospedagem coerente. Comparamos custo, energia e desempenho antes de decidir.

Ver o comparativo Ver a decisão

Como comparamos

O que avaliamos

O portal começou como site estático, mas o EcoBot precisa de um pequeno servidor Node.js. Por isso, rodar o servidor virou um critério obrigatório.

Custo anual

Quanto pagaríamos em um ano, somando hospedagem e domínio.

Energia e clima

Uso de energia renovável ou compensação de carbono, conferidos no Green Web Check.

Localização dos servidores

Servidores ou rede de distribuição (CDN) próximos de São Paulo carregam o site mais rápido.

HTTPS gratuito

Conexão segura incluída, sem custo extra e com renovação automática.

Servidor Node.js

Rodar o servidor Express do EcoBot e publicar direto do repositório Git a cada merge.

Suporte e documentação

Documentação clara e comunidade ativa, de preferência com material em português.

Resultado

Nossa decisão

R$ 0

durante o teste gratuito; depois, cerca de US$ 5 por mês no plano Hobby (estimativa)

Publicamos no Railway, com o endereço gratuito ecovida2026.up.railway.app.

  • É a plataforma adotada na disciplina e roda o servidor Node.js do EcoBot.
  • Publica sozinho a cada merge na branch principal, com HTTPS e logs no painel.
  • O subdomínio gratuito atende à entrega; o domínio ecovidaurbana.com.br (~R$ 40 por ano) fica para uma versão definitiva.

O ponto fraco é a energia: o Railway não aparece como hospedagem verde no Green Web Check. Para compensar, mantemos o site leve: CSS único, JavaScript pequeno, nada toca sozinho e imagens cada vez mais leves. Se a prioridade passar a ser a energia, a alternativa é o Render, que roda o mesmo servidor em infraestrutura verificada como verde.
